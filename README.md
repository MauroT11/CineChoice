## Welcome to CineChoice!

CineChoice is an movie recommendation platform designed to make your film & TV serie selection process easier. Whether you're in the mood for action, romance, or suspense, CineChoice provides the popular and top rated Films and TV Series.

- [Live Website](https://cine-choice-iota.vercel.app/)

## Features

- Browse through popular films and TV series
- Browse through top rated films and TV series
- Filter content by genres
- View detailed information about movies and TV shows
- Display film and TV series ratings
- User authentication and personalized watchlists
- Add films and TV series to your watchlist
- Responsive and user-friendly interface
- AI-enhanced styling using Claude 3.5
- Dynamic loading states for better user experience
- Protected routes for authenticated users
- User profile management

## Technologies Used

### Frontend

- Next.js 14: A React framework for building server-side rendered and statically generated web applications
- Clerk: A complete user authentication and management solution
- DaisyUI: A component library for Tailwind CSS
- Tailwind CSS: A utility-first CSS framework for rapid UI development
- Claude 3.5 AI: Integrated for enhanced UI/UX styling decisions

### Development Tools

- ESLint: For code quality and consistency
- PostCSS: For processing Tailwind CSS
- Vercel: For deployment and hosting

## APIs Used

The application utilizes The Movie Database (TMDB) API for fetching film and TV series data. TMDB is a community-built database that provides comprehensive information about movies and TV shows, including ratings, cast information, and more.

- [The Movie Database](https://www.themoviedb.org/)
